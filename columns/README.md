# コラムの書き方

このフォルダに Markdown ファイルを 1 つ置くと、サイトのコラムが 1 本増えます。
HTML や CSS を触る必要はありません。**GitHub の画面だけで完結します。**

書き終わったら、あとは運営が確認してマージするだけです。

## 1. 投稿の手順

1. このフォルダの [`_template.md`](./_template.md) を開き、右上の「Raw」を押して中身を全部コピーする
2. リポジトリのトップに戻り、「Add file」→「Create new file」を押す
3. ファイル名に `日付-内容.md` を入れる（例: `2026-10-19-hajimete-no-hardcore.md`）
4. コピーした中身を貼り付けて、自分の記事を書く
5. 下の「Commit changes」を押す

これで Pull Request ができます。書き込み権限が無い場合は、自分のコピー（フォーク）に
ブランチが作られ、自動的に Pull Request が開きます。

運営が中身を確認してマージすると、数分でサイトに公開されます。

- ファイル名がそのまま URL になります（例: `columns/2026-10-19-hajimete-no-hardcore.html`）
- ファイル名は半角英数字とハイフンにすると URL がきれいになります
- 記事は `date` の新しい順に並びます

## 2. 先頭の部分（front matter）

ファイルの先頭を `---` で挟んだ部分が、記事の情報です。

```markdown
---
title: はじめてのハードコア
date: 2026-10-19
author: ぷれいす
tags: ハードコア, 初心者
---
```

| 項目     | 必須 | 内容                                                          |
| -------- | ---- | ------------------------------------------------------------- |
| `title`  | 必要 | 記事のタイトル                                                |
| `date`   | 必要 | 公開日。`2026-10-19` の形（表示は自動で `2026.10.19` になる） |
| `author` | 任意 | 書いた人の名前。書くと一覧と記事の上に出る                    |
| `tags`   | 任意 | `,` か `、` で区切って並べる                                  |

`title` か `date` が無いとビルドが失敗し、Pull Request のチェックが赤くなります
（サイトが壊れることはありません）。書き方を間違えたときは、その赤い印が教えてくれます。

## 3. 本文の書き方

本文は Markdown です。よく使うものだけ挙げます。

```markdown
## 見出し

普通の段落。空行で段落を分けます。改行すると、そのまま改行されます。

- 箇条書き
- 箇条書き

1. 番号付き
2. 番号付き

**太字**と*斜体*と`コード`。

> 引用

[リンク](https://example.com)

![画像の説明](img/screenshot.png)

| 見出し | 見出し |
| ------ | ------ |
| セル   | セル   |

---

---
```

改行がそのまま `<br>` になる設定にしています。Markdown に慣れていない人でも、
書いたとおりに表示されます。

## 4. 画像

画像は `columns/img/` に置き（無ければ作ります）、本文では `img/ファイル名` と書きます。

```markdown
![ハードコアのワールド](img/world.png)
```

- `columns/img/` はそのまま公開されるので、置くだけで使えます
- 画像の説明（`![ ]` の中）は、目の不自由な人向けに必ず書いてください
- 大きい画像は避けてください（サイトが重くなります）

## 5. 気をつけること

- **HTML は書けません。** `<div>` などを書いても、そのまま文字として表示されます。
  ただし `<!-- メモ -->` のような HTML コメントは、画面に出ない目印として使えます。
- 記事のソース（`.md`）は公開されません。サイトに出るのは HTML に変換したものだけです。
- 下書きのまま置かないでください（置いた時点で公開されます）。下書きは Pull Request の
  ままにしておけば、マージするまで公開されません。

## 6. 手元で確認したいとき

Node.js がある人は、次のコマンドでサイト全体を `_site/` に書き出して確認できます。

```bash
npm install
npm run build
```

`_site/index.html` をブラウザで開くと、記事が一覧に出ているはずです。
`_site/` は生成物なのでコミットしないでください。
