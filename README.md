# Terraria JP 公式サイト

Terraria の日本コミュニティ向けの公式サイトです。

## 概要

- 素の HTML / CSS / JavaScript による静的サイト（フレームワーク無し）
- 公開は Cloudflare Workers。手書きのページは `public/` をそのまま配信し、コラムだけ D1 から組み立てて返す
- コラムはサイト内のフォームから投稿できる（Git を知らなくてよい）。画像もそのまま上げられる
- 投稿は「承認待ち」で保存され、運営が公開を決める（`/admin/columns`）
- Discord のマルチ募集を `/recruit` で見られる（中身は bot から受け取った写し。サイトから Discord は叩かない）。Discord 側で流れた募集は、書き込みの止まった時刻から自動で出なくなる
- Discord のイベント（これからの予定）が、お知らせページに自動で出る
- 整形・検査はエディタの保存時に自動で走る（コミット前のチェックは無し）
- Node.js（20.19.0 以上）は Stylelint と Wrangler に使う

## 料金（無料枠だけで動かす）

このサイトは「何があっても料金が発生しない」形で動かします。仕組みは次の 4 つです。

1. 使うのは **Workers と D1** だけ。どちらも無料枠を超えると「エラーになる」だけで、請求は来ない
2. 使った分だけ請求が来る **R2 は使わない**。記事の画像は D1 の `images` テーブルに入れる
3. アカウントは **Workers Free のまま**にする（支払い方法を登録しない・有料プランに変えない）
4. `npm run check:free` で、料金が発生しうる設定が混ざっていないか確かめる（デプロイ前に必ず通す）

無料枠と、超えたときの動き:

| 項目                 | 無料枠                                      | 超えたとき                 |
| -------------------- | ------------------------------------------- | -------------------------- |
| Workers のリクエスト | 100,000 / 日                                | その日はエラー（請求なし） |
| Workers の CPU       | 10ms / 回                                   | エラー（請求なし）         |
| 手書きのページ・素材 | 無制限（静的アセットは無料）                | —                          |
| D1 の行読み取り      | 5,000,000 / 日                              | エラー（請求なし）         |
| D1 の行書き込み      | 100,000 / 日                                | エラー（請求なし）         |
| D1 の容量            | アカウント合計 5GB・データベース 1 つ 500MB | 書き込みができなくなる     |

無料枠の壁に当たる前に、アプリ側でお断りする上限（すべて `worker/index.js` で決めている）:

| 項目               | 上限              |
| ------------------ | ----------------- |
| 画像 1 枚          | 1MB               |
| 画像の合計         | 400MB             |
| 画像のアップロード | 1 人 1 時間 20 枚 |
| コラムの投稿       | 1 人 1 時間 5 件  |
| 本文               | 100,000 文字      |

### 画像を R2 に置かない理由

R2 は無料枠（10GB）こそありますが、超えた分は請求が来ます。このサイトは「絶対に料金を
発生させない」ことを優先し、請求の入り口を作らないために R2 を使いません。画像は記事と
同じ D1 に入れます（1 枚 1MB・合計 400MB まで。1MB の理由は D1 の 1 行が 2MB までのため）。

次のどれかに当てはまったら、R2 への移し替えを考えます。

- 画像が 400 枚／400MB に近づいた
- 1 枚 1MB では足りない（スクリーンショットや高解像度の絵を載せたい）
- D1 のバックアップ（Time Travel・無料は 7 日分）が重くなってきた

移すときも、画像の URL（`/img/<id>`）は変えずに済みます。直すのは `worker/index.js` の
アップロードと取り出し、`worker/schema.sql`、`wrangler.jsonc` の 3 か所です。ただし R2 を
使うとカードの登録と従量課金を受け入れることになるので、先に運営で相談してください。

## ディレクトリ構成

```
public/                    そのまま配信されるページと素材（ここに入れたものだけが公開される）
├─ index.html              トップページ
├─ news.html               お知らせ
├─ server.html             サーバー紹介
├─ post.html               コラムの投稿フォーム
├─ admin/columns.html      コラムの承認（運営用。noindex）
└─ assets/
   ├─ css/
   ├─ js/
   └─ img/
worker/                    動くページと API（Cloudflare Workers）
├─ index.js                入口（振り分けと API）
├─ html.js                 コラムの一覧・記事の HTML
├─ recruit.js              マルチ募集の HTML
├─ recruitments.js         「いま立っている募集」の選び方と、流れる時刻
├─ events.js               「これからのイベント」を選ぶ条件
├─ markdown.js             Markdown → HTML
├─ migrations/             すでに動いている DB に列を足す SQL
├─ schema.sql              保存場所の定義
└─ seed.sql                動作確認用の記事
scripts/                   補助のスクリプト
├─ check-free-plan.mjs     料金が発生する設定が入っていないか確かめる
├─ check-events.mjs        「これからのイベント」の選び方を確かめる
└─ check-recruit.mjs       「いま立っている募集」の選び方を確かめる
dev/parts.html             共通パーツのプレビュー（開発用。公開されない）
```

## ブランチ構成

| ブランチ                      | 役割                                   |
| ----------------------------- | -------------------------------------- |
| `main`                        | 公開用。直接コミットしない             |
| `develop`                     | 開発の統合先。`feature` はここに集める |
| `feature/#<issue番号>_<内容>` | 作業用。1 つの issue につき 1 つ作る   |

作業は `feature` ブランチで行い、Pull Request は `develop` 向けに作成します。

## 公開

```bash
npm run check:free     # 無料枠だけで動くか確かめる
npm run check:events   # 「これからのイベント」の選び方を確かめる
npm run check:recruit  # 「いま立っている募集」の選び方を確かめる
npm run deploy         # Cloudflare Workers へ公開する
```

コラムは D1 に入っているので、記事が増えてもデプロイは要りません。
デプロイが要るのは、ページ・CSS・JS・Worker のコードを直したときだけです。

初回のセットアップ、合言葉の登録、承認ページの使い方は
[CLOUDFLARE.md](./CLOUDFLARE.md) を参照してください。
